Raw inline HTML

Some inline HTML elements have no native markdown form. <sub> and <sup> mark subscript / superscript and round-trip as RawInline nodes in the IR with format="confluence-storage". (We originally tried <kbd> here but Confluence strips it; <sub> and <sup> survive sanitisation cleanly.)

Water is H2O. Einstein's formula is E = mc2. Both the <sub> and <sup> markers survive the markdown -> Confluence storage round-trip; the IR carries them as RawInline through both legs.
