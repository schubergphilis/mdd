Inline formatting

A single paragraph that exercises every inline span the markdown reader produces: strong text, emphasis, strong emphasis combined, and inline code with a literal backtick ` inside it. The round-trip should preserve each span and the spacing between them without introducing stray whitespace or escape characters.

Confluence storage represents these as <strong>, <em> (sometimes nested for combined emphasis), and <code>. The fixture checks that the storage emission matches what Confluence's editor would write when the same span is composed in the UI.
