Task list

GFM task lists are unordered lists whose items start with [ ] (open) or [x] (done). Confluence storage maps each checked / unchecked item onto the <ac:task-list> macro with nested <ac:task> children carrying <ac:task-status> and <ac:task-body> elements.

  • Draft the proposal
  • Circulate for review
  • Incorporate feedback
  • Publish v1
  • Schedule the follow-up

The fixture mixes checked and unchecked items in a single list so the round-trip verifies both states. The item bodies are plain text — inline formatting inside task items lives in the task-list-nested.md companion fixture.
