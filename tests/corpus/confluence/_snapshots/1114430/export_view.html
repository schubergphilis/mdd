Fallback — unknown HTML block element

Spec 032 §"Fallback fixtures" pins this fixture as proof that a block-level HTML element with no first-class IR node round-trips as RawBlock(format="html", …). The CommonMark parser recognises raw-HTML blocks starting at column zero; the markdown reader maps those to RawBlock and the writer re-emits them verbatim inside Confluence storage.
