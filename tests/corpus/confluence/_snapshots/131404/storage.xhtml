Attachment link via ac:link

This fixture exercises the true <ac:link> with <ri:attachment> inline reference — distinct from the view-file macro card that the Confluence editor's paperclip-upload workflow produces (covered separately by niche-macros/view-file-macro.md).

The Confluence UI doesn't make this shape easy to compose, so this fixture is authored markdown-first with the inline reference written out as a raw {=confluence} block. The reference points at the attachment already uploaded to the "Attachment link" page (id 164069) via a <ri:page ri:content-title="..."/> child, making it a cross-page attachment link.
