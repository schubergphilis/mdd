Plain code block (no language)

A fenced code block with no language tag. Confluence storage typically represents this as <ac:structured-macro ac:name="code"> with <ac:plain-text-body><![CDATA[…]]></ac:plain-text-body> and no <ac:parameter ac:name="language">.

$ echo "hello"
hello
$ echo "world"
world

The CDATA section in storage must round-trip verbatim — the content between the fences includes meaningful whitespace and characters that would be HTML-escaped if treated as PCDATA.
