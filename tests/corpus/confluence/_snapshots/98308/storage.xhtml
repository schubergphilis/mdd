Plain paragraph

This page exercises the simplest possible Confluence storage element: a single paragraph of plain text with no inline formatting, no links, no macros.

If round-trip works for this fixture, the basic markdown → storage XHTML → markdown loop is intact. If it fails, every other fixture will fail too — this is the smoke-test bottom of the corpus.

The page is intentionally short so that any whitespace or escape- handling drift shows up quickly in a diff.
