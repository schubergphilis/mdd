Synthetic URI — confluence-page:

Spec 030 §"Synthetic URIs" defines confluence-page:<space>/<title> as the markdown-first form for a Confluence page link. The markdown reader resolves the URI to a ConfluenceLink(target_kind= "page", …) node; the writer maps it back to <ac:link><ri:page ri:space-key="…" ri:content-title="…" /></ac:link> in storage.

Bare in-space link: the project overview.

Cross-space link with the space key spelled out: external project home.

A page link with an anchor segment encoded as a semicolon-delimited extra: the API section.
