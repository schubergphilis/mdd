Callout — info (markdown-first)

The :::callout-info fenced div maps to Confluence's info macro (blue background). This fixture exercises the markdown-first authoring path for the info kind.

Heads up. Info callouts highlight context the reader needs to keep going without alarm. They are not warnings — use :::callout-warning for those.

A second paragraph keeps the macro body multi-block: the IR should preserve both paragraphs as children of the same Callout(kind="info") node. :::
