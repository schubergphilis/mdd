# Strikethrough

Sometimes text is ~~struck through~~ to mark it as removed without
deleting the history. GFM uses double-tildes; Confluence storage
renders that as `<s>...</s>`.

You can ~~strike through~~ a phrase, **strike through ~~with bold~~**,
or nest ~~strikethrough containing _emphasis_~~ — the IR round-trips
all three.
