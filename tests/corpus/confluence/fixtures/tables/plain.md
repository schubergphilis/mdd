# Plain table

A 3x3 table with a header row, no merged cells, no inline
formatting in cells. The simplest table case.

| Name    | Role     | Location  |
| ------- | -------- | --------- |
| Alice   | Engineer | Amsterdam |
| Bob     | Designer | Utrecht   |
| Charlie | PM       | Rotterdam |
