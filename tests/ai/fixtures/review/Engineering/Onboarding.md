# Onboarding

Welcome to the engineering team.

## Laptop Provisioning

Your laptop is ordered via the IT portal.
Submit a request at https://it.example.com and select "New employee laptop".

## IT Portal Access

Log in to the IT portal using your company SSO credentials.
You will need to set up 2FA on your first login.

## Software Setup

Install the following tools:
- Homebrew
- Git
- Docker Desktop

## Slack

Join the #engineering and #general channels.
