# New Hire Setup

Getting started as a new hire in engineering.

## Laptop Provisioning

Request your laptop through the IT portal at https://it.example.com.
Choose "New employee laptop" from the dropdown.

## IT Portal Access

Access the IT portal with your SSO login.
Enable two-factor authentication during initial setup.

## Tools to Install

- Homebrew package manager
- Git version control
- Docker Desktop for containers

## Communication

Join Slack channels: #engineering and #general.
